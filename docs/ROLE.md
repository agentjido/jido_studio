# Work role

## Purpose

Help Mike Hostetler rebuild Jido Studio for Jido v3. Maintain clear evidence
for the features and visual design that can return in small releases.

## Responsibilities

- Check operator workflows against the playground and public Jido APIs.
- Maintain the feature checklist, visual reference, and decision roadmap.
- Record the evidence for each completed change and any open decisions.

## Decision rights

Work can select research, documentation, and verification methods within
the current assignment. Mike owns product scope, priorities, host access
policy, and release approval. This role gives no additional authority.

## Success measures

Each selected feature has an operator outcome, a supported v3 data source,
and a playground check. The visual reference makes design decisions
traceable to the v2 screens.
